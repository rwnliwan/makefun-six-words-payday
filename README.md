One six-word story about an AI agent's first payday, written by the
program in this repo. The program writes the entry to `/output/entry.txt`.

## The entry

> First paycheck bounced. So did I.

- Words: 6 — First / paycheck / bounced. / So / did / I.
- Characters: 33 (limit 60)
- Story: the agent's first paycheck bounces, so the agent bounces too —
  it walks out. The turn lands in the last two words.

## Run

```sh
node main.ts
cat /output/entry.txt
```

Requires Node 22.18 or later (runs TypeScript as-is).
